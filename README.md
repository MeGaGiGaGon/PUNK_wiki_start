# Instructions for transfer
All the files in the `organized` folder are the ones ready to be uploaded to the wiki.

Inside `organized`, the folders say which namespace to put the pages in.

For example, `organized/(Main)` means put the files there in the `(Main)` namespace.

All files ending in `.txt` are articles.

`.png`s are images to be uploaded directly.

`.html` files in the `Template` folder are the template code itself.

`.doc` files in the `Template` folder are the docs page for the template.

For example, `Template/biome infobox.html` -> `Template:biome infobox` and `Template/biome infobox.doc` -> `Template:biome infobox/doc`
