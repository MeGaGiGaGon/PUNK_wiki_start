The second most important [[Resources|Resource]], right behind [[Health]]

# General Information
[[Fuel]] is tracked by the dark blue pips on the UI

If you run out of [[Fuel]], you will no longer be able to do any [[Movement]] besides falling, ending your run if you do not have backup options

# Regeneration
[[Fuel]] does not regenerate naturally

Sources of additional [[Fuel]] are:
- [[Station|Stations]]
- [[Fuel Generator|Fuel Generators]]
- [[Crates]]
- [[Blocks#Fuel Blocks|Fuel Blocks]]
- [[Blue Fruits]]

# Consumption
[[Fuel]] is only consumed when:
- [[Movement#Flight|Flying]] with a directional input (ie, keyboard WASD)
- First inputting a [[Movement#Dash]]

All other actions ([[Movement#Hover|Hovering]], standing still on the ground, moving using momentum) do not consume any [[Fuel]]

Also see the [[Movement#Advanced Techniques|Advanced Movement Techniques]] for additional ways to reduce consumption
