Modules are ordered in a depth-first search starting from the weapon/body/gadget and search Up, Right, Down, and Left.

Described in text, the process is:
* Starting from the weapon/body/gadget
*# Give the current module the next number
*# Look at directly adjacent module slots in the order Up, Right, Down, Left
*#* If a module has already been numbered, don't consider it
*#* Be wary of modules without all 4 connections, don't consider modules not actually connected
*# If you found a new module, treat it as the current module and go back to 1
*# Otherwise, treat the module with number one less than the current module as the new current and go back to 2
* If you reach the weapon/body/gadget again and it has no more valid modules, you are done

== Spread Ordering ==
Spread cannot go below zero, so it is important that <code>- Spread</code> modules go after <code>Extra Projectile</code> modules.

For example, despite having more than enough <code>- Spread</code>, this build ends up with some left because the <code>Extra Projectiles</code> are later in the order.

[[File:Module Ordering Spread Example.png]]

By putting the <code>- Spreads</code> later in the order instead, the build works as intended with zero ending spread.
